# งาน (Tasks)

## 1. Schema และ migration

- 1.1 เพิ่ม `branches`, `tables.branch_id` พร้อม unique (branch_id, number), `users`, `user_branches`, `staff_sessions` ใน `db/schema.ts` (D1, D5); ตรวจว่า `drizzle-kit generate` สร้าง migration เดียว
- 1.2 แก้ migration ด้วยมือ ให้เพิ่มสาขา SIAM และเติม `tables.branch_id` ก่อนตั้ง NOT NULL (D2); ตรวจกับสำเนาฐานข้อมูลก่อนการเปลี่ยนแปลงว่าทุกโต๊ะ session ออร์เดอร์ และบิล อยู่ใต้ SIAM และเลขบิลเดิมไม่เปลี่ยน

## 2. สาขาในชั้น service และ seed

- 2.1 ทำให้การค้นหาโต๊ะรู้จักสาขา (`getTable(branchCode, number)`) และเลขบิลมีรหัสสาขา (D3); ตรวจด้วย service test: โต๊ะเลขเดียวกันใน SIAM และ ASOK ได้ session แยกกัน และเลขบิลเป็น `SIAM-T05-…` / `ASOK-T05-…`
- 2.2 จำกัดขอบเขตฟังก์ชัน service ของคอนโซลตามสาขา และเพิ่มการตรวจความเป็นเจ้าของ (D7); ตรวจด้วย test: ภาพรวมและประวัติแสดงเฉพาะสาขานั้น และ id ของรายการ/บิลจากสาขาอื่นได้ 404 โดยข้อมูลไม่เปลี่ยน
- 2.3 Seed โต๊ะ SIAM (10) และ ASOK (6) และบัญชีพนักงานสองบัญชีพร้อมรหัสผ่านที่แฮชแล้ว (D8); ตรวจจำนวนและการสังกัดด้วย query
- 2.4 เพิ่มโหมด seed แบบไม่ลบข้อมูล `--users-only` (D8); ตรวจด้วย test: บนฐานข้อมูลที่มีบิลที่จ่ายแล้ว การรันสองครั้งเพิ่ม ASOK และผู้ใช้ทั้งสอง คงบิลและรายการไว้ และไม่สร้างข้อมูลซ้ำ

## 3. การยืนยันตัวตน

- 3.1 `lib/auth.ts`: แฮช/ตรวจรหัสผ่านด้วย scrypt, สร้าง/ค้นหา/ต่ออายุ/ลบ session, `requireStaff(branchCode?)` (D5, D6); ตรวจด้วย unit test: แฮชแล้วตรวจกลับได้ รหัสผ่านผิดถูกปฏิเสธ หมดอายุหลัง 24 ชม. และกฎการต่ออายุ
- 3.2 `/api/auth/login` และ `/api/auth/logout` พร้อมข้อความ error แบบกลาง ๆ และ flag ของ cookie; ตรวจด้วย test: ล็อกอินถูกต้องได้ cookie รหัสผ่านผิดไม่ได้ cookie และ logout ลบ session

## 4. Routes และ UI

- 4.1 ย้ายหน้าและ API ฝั่งลูกค้าไปใต้ `/b/[branch]/…` แสดงชื่อสาขา และลบ `/t/…` (D4); ตรวจว่า `/b/SIAM/t/5` ใช้งานได้ และ `/t/5` แสดง "table not found"
- 4.2 ย้ายหน้าและ API ของคอนโซลไปใต้ `/[branch]` เรียก `requireStaff` ทุกจุด ให้หน้าเว็บ redirect ไป `/login?next=…` และมีหน้า 403; ตรวจด้วย test: เรียก console API โดยไม่มี cookie ได้ 401 และสาขาที่ไม่ได้สังกัดได้ 403
- 4.3 หน้า `/login`, การ redirect/ตัวเลือกสาขาที่ `/console`, ชื่อสาขา + ปุ่ม Switch branch + Log out ที่ส่วนหัวคอนโซล; ตรวจว่าผู้ใช้สาขาเดียวเข้า SIAM ทันที และผู้ใช้หลายสาขาเห็นตัวเลือกสาขา
- 4.4 ใบเสร็จและประวัติแสดงสาขา (ตาม delta ของ restaurant-console); ตรวจว่าใบเสร็จของ SIAM แสดงชื่อสาขา SIAM
- 4.5 ปรับลิงก์ใน demo index และ README (URL ใหม่ บัญชีทดลอง ขั้นตอน migration); ตรวจว่าคำสั่งใน README รันได้ตามที่เขียนบนฐานข้อมูลใหม่

## 5. การทดสอบรวม (Integration)

- 5.1 ปรับ browser walkthrough: flow ลูกค้าใต้ `/b/SIAM/…`, การล็อกอินพนักงาน, การ redirect ของผู้ใช้สาขาเดียว, ตัวเลือกและการสลับสาขาของผู้ใช้หลายสาขา, การแยกข้อมูลของ ASOK, 403 สำหรับ `siam.staff` บน ASOK และ logout; ตรวจว่า `npm test`, `npm run e2e`, lint, typecheck และ build ผ่านทั้งหมด
